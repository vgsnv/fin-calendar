# Известное будущее

Метод личного финансового планирования и материалы вокруг него.

## Структура

- `izvestnoe-buduschee.md` — главный документ: Секция А (метод, канон) + Секция Б (спецификация прототипа)
- `prototypes/` — сборки кликабельных прототипов
- `archive/` — ранние материалы линии «Гибкие финансы» (устаревшая версия метода, историческая ценность)

## Правила ведения

- Решения о методе меняют Секцию А, интерфейсные — Секцию Б; при противоречии права Секция А
- Каждое содержательное изменение — отдельный коммит с внятным сообщением
- Прошлые версии не редактируются — история и есть хронология
