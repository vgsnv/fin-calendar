# Заметки для будущей спецификации приложения

Накопленные решения из обсуждений канона, которые должны попасть в Секцию Б, когда она будет писаться заново.

- **Выбор календаря.** В онбординге объяснить развилку «свой / общий» и цену каждого (подстройка под приходы и ожидание ≤6 дней — против общей печатной ленты и буфера в один приход). По умолчанию — свой; общий предлагать при 3+ приходах в месяц и для совместного бюджета.
- **Граница финнедели** — настройка с рекомендацией субботы; в общем календаре сдвигает даты, не меняя номера спринтов.
- **Статья после даты платежа** закрывается сама на раскладке спринта с её датой — интерфейсу не нужны состояния «ждёт подтверждения».
- **Дробность сумм** — настройка округления живёт в приложении, канон отдаёт точные цифры.
- **Производственный календарь** — показывать сетку до и после его учёта, расхождения подсвечивать (январский стык).
- **Вход рядом с длинным спринтом** — окно сбора начинается со входа (С10), сумма размазывается по имеющимся приходам общей балансировкой; если план не сходится — общие правила П8–П9.
