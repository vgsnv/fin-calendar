# Свой календарь

*Календарь по опорным датам собственных приходов: старты спринтов идут за деньгами. Основа и рассуждение — в «[Календаре](index.md)»; используется по умолчанию.*

---

Опорные даты — даты собственных приходов денег: старты спринтов идут за деньгами.

```
1. Расставить номинальные опорные даты на весь горизонт.
2. Каждую прогнать через правила плательщика: дата попала на
   выходной или праздник — деньги приходят в последний рабочий
   день до неё.
3. Каждую фактическую дату сдвинуть вперёд до ближайшей границы
   финнедели (включая сам день). Это старт спринта. Даты с
   одинаковым стартом складываются в один.
4. Старты по возрастанию — границы спринтов. Длина спринта —
   число финнедель до следующей границы.
```

Проверочный инвариант: сумма длин всех спринтов между любыми двумя границами равна числу финнедель между ними — ни одна не потеряна и не посчитана дважды. Реализация, у которой это не сходится, неверна.

Эталонные расчёты — в `../tests/own-calendar-2027.md`. Три вывода из них:

- **Одна опорная дата в месяц (25-е):** спринты по 4 финнедели, несколько раз в год — по 5.
- **Две (5-е и 20-е):** спринты по 2, длинные — по 3, примерно раз в квартал.
- **Три (1-е, 10-е, 20-е):** обычные длины у спринтов разные, и отклонения случаются в обе стороны — длина спринта просто вычисляемая величина.

**Длинный спринт** здесь — спринт длиннее обычной длины своей опорной даты. Производственный календарь учитывается отдельным проходом: сетка считается до его учёта и после, расхождения показываются (кейс 4 в тестах: новогодние каникулы переносят длинный спринт на другую опорную дату).

Свойства своего календаря: старты стоят вплотную к приходам — деньги ждут раскладки не дольше шести дней; лента личная и перестраивается при смене графика приходов.
